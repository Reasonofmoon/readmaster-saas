# Harness Run Records

하네스 실행 기록은 작업별 디렉터리에 보관한다. 디렉터리 이름은
`YYYY-MM-DD-task-name/` 규칙을 사용하며, `task-name`은 실행 목적을 식별할 수 있는
짧은 비민감 이름으로 정한다. 같은 작업을 재시도할 때는 기존 기록을 덮어쓰지 않고
재시도 범위를 식별할 수 있는 새 기록을 만든다.

## 허용 필드

실행 기록에는 다음 필드만 기록한다.

- 작업 목적과 범위
- 입력의 비민감 식별자와 hash
- 담당 역할과 handoff 상태
- 실행한 실제 명령과 종료 코드
- 검증 결과와 미검증 항목
- 사람 gate 결정의 비민감 메타데이터
- 변경 파일과 재시도 범위

명령과 결과는 실제 실행한 것만 기록하고, 실행하지 않은 명령이나 존재를 확인하지
않은 도구·서비스를 완료 근거로 적지 않는다. 사람 gate가 필요한 경우 승인 여부를
AI가 추정하지 않고 `waitingForHuman`과 비민감한 결정 메타데이터만 기록한다.

## 기록하지 않는 정보

원문, OCR 본문, 정답 초안, 내부 프롬프트, API key, 개인정보는 실행 기록에 기록하지
않는다. 본문 대신 비민감 식별자, hash, version, 상태, 경고, 내부 산출물 식별자와
범위만 사용한다.

## 실행 기록 검토

최종 기록은 변경 파일과 실제 명령의 종료 코드, 통과·실패·미검증 항목, 남은 재시도
범위를 함께 보여야 한다. 실패나 불확실성이 있으면 완료로 표시하지 않고 차단 상태와
근거를 남겨 사람 검토로 보낸다.
